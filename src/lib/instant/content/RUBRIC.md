# Instant Income Facebook post authoring rubric

Use this when adding or editing posts in `src/lib/instant/content/`.

## Counts and IDs

- Target: **250 posts total** across 8 niches (6 × 31 + 2 × 32).
- IDs are stable: `fb-<prefix>-01` … with zero-padded numbers.
- Prefixes: `wl`, `mmo`, `hf`, `bs`, `rel`, `tg`, `pet`, `hg`.
- `niche` must match the file's niche exactly.

## Link placeholder

- `body` contains `{{LINK}}` exactly once.
- Never put `{{LINK}}` in `title`.
- Place the link in the last third, framed as a soft resource (not a hard pitch).

## Voice

- Write like a real person posting in a Facebook group.
- Tips, questions, empathy, soft resource share.
- Short and medium sentences. Concrete details. No spam triggers.
- **Do NOT** invent testimonials, earnings, weight-loss results, or personal product use.
- Follow Instant safety rules (no guaranteed results, no fake urgency, no rule evasion).

## Styles (rotate)

helpful, short, detailed, curiosity, empathetic, expert, soft_sell, skeptical_friend

## Angles

Each niche file must cover distinct angles (beginner mistake, timing, group etiquette, habit, tool filter, etc.). Do not reuse closing paragraphs across posts.
